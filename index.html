GST e-Invoicing and e-Way Bill

Softcell Technologies · 2022 – present

  • PHP
  • Laravel
  • MySQL
  • REST APIs
  • API encryption
  • Cron jobs

I owned the integration with a government-authorized GST API from analysis and design through development, testing, and production rollout. The order and invoicing workflow now generates and cancels IRN and e-Way Bill records automatically, so teams are not re-entering the same invoices on a portal, and statutory compliance stays attached to the order itself.

Requests are encrypted before they leave our system and responses are decrypted on the way back, which is how the provider exchange stays protected. When the API fails or the payload is rejected, error handling and retry logic take the failure instead of a silent drop, and I support the business teams when a production case needs a person who knows the flow.
